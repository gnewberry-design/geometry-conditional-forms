📖 Lesson Guide / Overview

➡️ Conditional

If p, then q: p → q

🔁 Converse

Switch the parts: q → p

🚫 Inverse

Negate both: ¬p → ¬q

🔀 Contrapositive

Switch AND negate: ¬q → ¬p

🧮 Algebraic Proof

A logical argument using algebra and mathematical properties.

How can inverse and contrapositive statements help us understand and prove mathematical relationships?

Think about what happens when we negate or switch parts of a statement—and which forms must share the same truth value.

  • Write conjectures.
  • Identify a conditional statement's hypothesis and conclusion.
  • Write conditional, converse, and biconditional statements.
  • Recognize counterexamples and distinguish true from false statements.

Lesson length: Approximately 45–50 minutes. Essential focus: Conditional and contrapositive are logically equivalent; inverse and converse are logically equivalent.

🔔 Warm-Up / Bell Ringer

Original: “If a figure is a square, then it has four sides.”

  1. Identify the hypothesis.
  2. Identify the conclusion.
  3. Write the converse.
  4. Is the converse always true? Explain.
🔎 Reveal teacher answers

Hypothesis: the figure is a square. Conclusion: it has four sides. Converse: “If a figure has four sides, then it is a square.” This is false: a non-square rectangle has four sides.

👨‍🏫 I Do - Direct Instruction (Learn)

A conditional statement is written p → q.

FormSymbolHow to write it
Conditionalp → qIf p, then q
Converseq → pIf q, then p
Inverse¬p → ¬qIf not p, then not q
Contrapositive¬q → ¬pIf not q, then not p

🔢 Model Example

Original: If a number is divisible by 4, then it is even.

  • Converse: If a number is even, then it is divisible by 4.
  • Inverse: If a number is not divisible by 4, then it is not even.
  • Contrapositive: If a number is not even, then it is not divisible by 4.
⭐ A conditional and its contrapositive are logically equivalent. The converse and inverse are also logically equivalent.

🧮 Model a Proof by Contrapositive

Claim: If x² is odd, then x is odd, where x is an integer.

Prove the contrapositive: If x is even, then x² is even.

Let x = 2k for an integer k. Then x² = (2k)² = 4k² = 2(2k²), which is even. Therefore the contrapositive—and the original claim—is true. ✅

🤝 We Do - Guided Practice

Example 1: If a triangle is equilateral, then all three sides are congruent.

👀 Show inverse and contrapositive

Inverse: If a triangle is not equilateral, then not all three sides are congruent.

Contrapositive: If not all three sides of a triangle are congruent, then the triangle is not equilateral.

Example 2: If two angles are vertical angles, then they are congruent.

💬 Work together to write the inverse and contrapositive. Ask: Which one is logically equivalent to the original?

👀 Show suggested answers

Inverse: If two angles are not vertical angles, then they are not congruent.

Contrapositive: If two angles are not congruent, then they are not vertical angles.

✏️ You Do - Independent Practice

  1. Write the inverse: If a number is a multiple of 10, then it is a multiple of 5.
  2. Write the contrapositive: If an angle is acute, then its measure is less than 90°.
  3. Write the inverse and contrapositive: If a polygon is a triangle, then it has three sides.
  4. Explain how the converse differs from the contrapositive.
  5. Identify the two pairs of logically equivalent forms.

🧩 Support: use the chart and sentence frames. 🚀 Extension: test truth values with counterexamples or proofs.
